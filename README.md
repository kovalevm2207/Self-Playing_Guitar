# Self-Playing_Guitar
Создание механизма, способного воспроизводить различные мелодии на большом количестве акустических гитар.

Подбор электроники для закупки в России, обоснование компонентов, полная карта выводов, питание без компьютера и архитектура синхронизации: [проект первого прототипа](docs/electronics-design-ru.md). Обновлено 15 сентября 2026: NEMA-17, DRV8825, новые кандидаты соленоидов, ключи и аппаратная остановка.

Для начала сборки: [схема подключения одной струны и принцип работы](docs/single-string-wiring-ru.md).
