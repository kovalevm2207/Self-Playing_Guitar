# Self-Playing_Guitar
Создание механизма, способного воспроизводить различные мелодии на большом количестве акустических гитар.

[Лифлет проекта — PDF и исходник генератора](docs/leaflet/README.md).

## Структура репозитория

| Каталог | Содержимое |
|---|---|
| [software](software/README.md) | Приложение, прошивка Uno, общий протокол, тесты и CMake/Nix |
| [docs](docs) | Документация устройства и лифлет проекта |
| `3DМакет` | Модели механики |
| `Эскизы` | Эскизы устройства |
| `Источники` | Референсы и материалы исследования |

Вся разработка ПО выполняется внутри `software/`:

```bash
cd software
nix develop
cmake --preset debug
cmake --build --preset debug
ctest --preset debug
bash tools/run-linux.sh
```

Быстрый запуск в WSL из корня репозитория: `bash software/tools/start.sh`.

Подбор электроники, полная карта выводов, инструкция подключения и архитектура синхронизации: [проект первого прототипа](docs/electronics-design-ru.md).
