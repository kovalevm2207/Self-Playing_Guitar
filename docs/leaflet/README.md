# Лифлет проекта

[Готовый PDF для печати](self-playing-guitar-leaflet.pdf).

Исходник генератора — `create_leaflet.py`. Для пересборки из корня репозитория:

```powershell
python docs/leaflet/create_leaflet.py
```

Нужен Python с библиотекой `reportlab` и шрифты Arial из `C:/Windows/Fonts`.
Генератор берёт эскиз из каталога `Эскизы` и сохраняет PDF рядом с собой,
независимо от текущего рабочего каталога. Предпросмотры и временные файлы
в документацию не включаются.
