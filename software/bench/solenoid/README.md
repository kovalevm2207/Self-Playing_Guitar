# Отдельный тест JF-1253B, 24 VDC / 1,5 A

Один канал: Uno D6 → TC4427EPA → IRLZ44N → катушка от внешнего БП 24 В.
[Схема с ножками компонентов](../../../docs/wiring/solenoid-jf1253b-24v-tc4427.png)
находится в корневом каталоге документации репозитория.

Нет автоматического запуска при подключении USB или reset. Команда PULSE
выдаёт один импульс, по умолчанию 50 мс. Разрешены 10–100 мс, затем обязательная
пауза 5 секунд после выключения, включая STOP. Повторные команды во время
импульса или паузы отклоняются, в очередь не ставятся. Неизвестные команды,
повреждённые и слишком длинные строки выключают выход.

## 1. Установить программы

Инструкция ниже — для **Windows PowerShell**. Нужны Git и обычный
[Python 3.13 для Windows](https://www.python.org/downloads/windows/)
с компонентами pip, Tcl/Tk и Python launcher (`py`). Qt, CMake, Nix,
Arduino IDE и расширение PlatformIO для VS Code для этого теста не нужны.

Если работаешь в WSL, для этого теста открой **Windows PowerShell**.
Клон должен лежать на диске Windows: например, `C:\Projects\Self-Playing_Guitar`
и `/mnt/c/Projects/Self-Playing_Guitar` — одна папка. USB остаётся в Windows,
передавать его в WSL не нужно. Все команды ниже вводятся в PowerShell.

Проверь Python:

```powershell
py -3.13 --version
py -3.13 -m tkinter
```

Ожидаются `Python 3.13.x` и тестовое окно tkinter. Закрой его.
Если `py` не найден или нет tkinter, сначала исправь установку Python.

## 2. Подготовить клон и зависимости

Открой PowerShell **в корне своего клона** — там, где лежат `README.md`
и папка `software`. Выполняй команды по очереди, дожидаясь успешного завершения:

```powershell
git switch software
cd software\bench\solenoid
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r tools\requirements.txt
```

Установка требует интернета. Окружение `.venv` локальное и не попадает в Git.
Активировать его не требуется: в командах явно указан его Python.
Зависимости: PlatformIO Core 6.2.0 и pyserial 3.5.
Все дальнейшие команды выполняй в **`software\bench\solenoid`**, в том же окне.

Проверь окно управления без подключения к Arduino:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start_control.ps1 -Check
```

Ожидается `PASS: correct firmware handshake, manual pulse only, cooldown, STOP, disconnect`.
Проверка использует подставной порт, к плате не подключается и катушку не включает.

## 3. Собрать схему без питания

- Собрать обесточенную схему. TC4427: 5 В от Uno; катушка: отдельные 24 В.
- Общая GND, входной и затворный резисторы 10 кОм, последовательный 100 Ом,
  развязка питания драйвера и защитный диод 3 А (на схеме 1N5408).
- Пока схема не проверена и защитный диод не установлен, питание 24 В не подавать.
- Питание шагового двигателя для этого теста выключить. Прошивка дополнительно
  держит D4 HIGH (EN TMC2209 выключен), D2 LOW; шагов не выдаёт.
- Закрепить корпус соленоида, оставить штоку место для движения;
  не держать пальцы в зоне его хода.

**24 В не подключать к Uno или TC4427.** Во время загрузки прошивки
и подключения окна питание 24 В оставить выключенным; Uno питается от USB.

## 4. Найти порт Uno

Подключи Uno USB-кабелем с передачей данных и выполни:

```powershell
.\.venv\Scripts\python.exe -m platformio device list
```

Найди порт платы, например **COM5**. Если устройств несколько, сравни список
с отключённой и подключённой Uno. Bluetooth-порты к ней не относятся.
Далее COM5 — пример: **замени его своим портом**.

## 5. Загрузить тестовую прошивку

Закрой SelfGuitar, Arduino Serial Monitor, старые окна тестов и другие
программы, использующие порт. Команда **заменит текущую программу Uno**:

```powershell
.\.venv\Scripts\python.exe -m platformio run -d . -e uno -t upload --upload-port COM5
```

При первом запуске PlatformIO скачает платформу AVR и инструменты сборки.
Дождись **`SUCCESS`**. Если загрузка завершилась ошибкой, сначала устрани её.

## 6. Открыть окно и выполнить один импульс

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start_control.ps1
```

1. Выбери порт Uno и нажми **«Подключить»**.
2. Дождись `SOLENOID READY V1; ...` в журнале и состояния
   **«Выход выключен. Готов к одному импульсу»**. Кнопка станет доступной.
3. Проверь собранную схему, затем включи БП катушки **24 В**.
4. Оставь **50 мс**, нажми **«Один импульс»** один раз.
5. В журнале должны появиться `OK PULSE 50` и `DONE; output=OFF; ...`.
   Ожидается краткое срабатывание и отпускание соленоида. После выключения
   будет обязательная пауза 5 секунд, затем кнопка снова станет доступной.

**«СТОП» / Esc** отправляет STOP. Выключение по таймеру выполняет сама Uno,
связь с окном для него не нужна. При закрытии окна дополнительно отправляется
STOP без ожидания ответа. После теста выключи 24 В, затем отключи окно и USB.

При следующих запусках достаточно открыть PowerShell в `software\bench\solenoid`
и выполнить команду запуска окна. Заново устанавливать зависимости и загружать
ту же прошивку не требуется. Если на Uno загрузили другую программу,
сначала повтори шаг 5.

## Если не работает

| Симптом | Что проверить |
|---|---|
| `py` не найден / `No suitable Python runtime found` | Установить Python 3.13 с launcher и открыть новое окно PowerShell. |
| Нет `.venv\Scripts\python.exe` | Повторить шаг 2 из нужной папки. Окружение Windows создавать Windows Python, не Linux Python в WSL. |
| `No module named serial` / `platformio` | Повторить установку `requirements.txt` через Python из `.venv`, как в шаге 2. Пакет называется `pyserial`, не `serial`. |
| Нет tkinter / ошибка Tcl/Tk | Исправить установку Python с компонентом Tcl/Tk, проверить `py -3.13 -m tkinter`. |
| Нет порта Uno | Проверить кабель с передачей данных и Диспетчер устройств; при необходимости установить USB-драйвер изготовителя платы. |
| `Access is denied` / порт занят | Закрыть другие окна управления и мониторы порта, проверить номер порта. |
| Ошибка `avrdude` при загрузке | Проверить плату Uno, порт и кабель. Сохранить полный текст ошибки upload. |
| Окно ждёт `SOLENOID READY V1` | Проверить успешную загрузку именно этого теста и правильный порт. Переподключиться; если баннер не появился — нажать RESET на Uno при выключенных 24 В. |
| Есть `OK PULSE` и `DONE`, но нет движения | Команда дошла до прошивки; сигнал на выводе и ток катушки этим ещё не подтверждены. Проверить 24 В БП, 5 В между ножками 6–3 TC4427, общую землю, распиновку, диод и D6. Короткий импульс мультиметр может пропустить. |

Длительность не увеличивать вслепую при отсутствии хода: сначала проверить
питание, схему, ток и свободу механики. Начальные 50 мс не гарантируют
полного хода под нагрузкой.

## Без окна

Монитор последовательного порта: 115200 бод, команды заканчиваются LF:

| Команда | Результат |
|---|---|
| `PULSE` | Один импульс 50 мс |
| `PULSE 20` | Один импульс 20 мс, допустимо 10–100 |
| `STOP` | Выключить выход, сохранить обязательную паузу |
| `STATUS` | READY, PULSING или COOLDOWN с оставшимися миллисекундами |

После старта: `SOLENOID READY V1; ...`. После импульса: `DONE; output=OFF; ...`,
после паузы: `STATE READY`. Факт GPIO-импульса не подтверждает механический ход.

## Ограничения прошивки

Timer1 в режиме CTC с делителем /64 отключает D6 в прерывании. Основной цикл
дополнительно проверяет длительность по millis. Это независимость от задержки
основного цикла при работающих прерываниях, не защита от любого отказа CPU,
неисправности MOSFET или ошибочного подключения. Timer1 занят исключительно
этим тестом. Прошивка рассчитана на ATmega328P Uno при 16 МГц.

Пауза — ограничение теста, не измерение температуры и не паспортный режим
катушки. Reset сбрасывает её состояние: не использовать переподключение
для ускорения серии. Начальные 50 мс — пробный режим,
не гарантия полного хода под нагрузкой.

## Проверки без платы

Из `software/bench/solenoid` в PowerShell:

```powershell
.\.venv\Scripts\python.exe -m platformio run -d . -e uno
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start_control.ps1 -Check
```

В штатном окружении Nix сборка без платы: из `software` —
`nix develop --command pio run -d bench/solenoid -e uno`.
Логика самой прошивки, команды и ISR проверяются CTest `solenoid_bench`
с подставными регистрами AVR. Это не эмуляция тактов микроконтроллера.
