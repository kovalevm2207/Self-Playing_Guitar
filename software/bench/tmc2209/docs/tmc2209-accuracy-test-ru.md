# Точность перемещения и возврата

Отдельная прошивка `tmc2209_accuracy_test` и окно
`tools/tmc2209_accuracy_control.py`. Прошивка использует общий генератор
переездов из `src/tmc2209_fret_test.cpp` с флагом `ACCURACY_TEST`.

Arduino выдаёт импульсы, а реальную координату измеряет пользователь.
Нужны закреплённая линейка с указателем, штангенциркуль подходящего диапазона
или индикатор. Разрешение прибора должно позволять проверить выбранный допуск.
Для измерения всей длины 125 мм нужен прибор с соответствующим диапазоном.

## Подключение и загрузка

Существующее подключение: STEP D2, DIR D3, EN D4, общий GND, внешнее питание
драйвера. Расчёт: GT2, шкив 20 зубьев, 1/8 микрошаг, 1600 STEP/оборот,
40 STEP/мм. Микрошаг должен быть установлен на драйвере: эта прошивка
не настраивает его по UART. При другой механике коэффициент нужно изменить.
Концевики и StallGuard здесь не обрабатываются; обеспечьте свободный ход.

Закройте остальные окна с COM5. В терминале из корня проекта:

```powershell
& "$env:USERPROFILE\.platformio\penv\Scripts\platformio.exe" run -e tmc2209_accuracy_test -t upload --upload-port COM5
powershell -ExecutionPolicy Bypass -File .\tools\start_accuracy_control.ps1
```

Если Arduino имеет другой порт, замените COM5 и выберите его в окне.
Окно требует обычный Python с tkinter и pyserial; launcher также ищет
pyserial в окружении PlatformIO. Для установки: `python -m pip install -r tools/requirements.txt`.

## Измерение

1. Подключитесь в окне и дождитесь `ACCURACY READY V2`.
2. Установите каретку так, чтобы впереди хватало места для заданного хода.
   Нажмите «Удержать мотор для установки нуля». Это включает удержание,
   автоматического поиска исходной точки нет.
3. После фиксации вала обнулите прибор или отметьте исходную координату.
   Подтвердите галочку в окне. Обнуление до включения удержания может дать
   ошибку из-за начального смещения ротора.
4. Задайте ход 1–300 мм, время одного переезда 300–5000 мс, 1–30 циклов
   и допуск. Для начала: 125 мм, 800 мс, 5 циклов, ±0,5 мм.
5. Нажмите «Начать измерения». После остановки в дальней точке измерьте
   фактическую координату относительно исходного нуля, например 124,8 мм.
   Введите её и нажмите «Записать и продолжить» или Enter.
6. После возврата измерьте отклонение относительно того же нуля, например
   −0,15 мм. Вводите знак. Повторяйте до конца серии.

Каждый цикл — ход вперёд и возврат. В точках мотор удерживает позицию;
на ввод даётся 120 секунд. Пробел, Esc и кнопка СТОП отключают драйвер.
При потере связи удержание отключается через 2 секунды. После отключения,
срыва или прерывания восстановите исходную точку и установите ноль заново.
Не передвигайте каретку руками во время измерений. Перед новой серией
рекомендуется заново установить исходный ноль.

## Результат

Ошибка точки = измеренная координата − целевая координата. Окно показывает
максимальную абсолютную ошибку всей серии и возвратов. «В допуске» появляется
только после всех измерений и подтверждения завершения от прошивки.
Прерванная серия сохраняется как неполная.

CSV с каждой точкой и JSON с итогами сохраняются в `.pio/accuracy-logs/`.
JSON также содержит среднюю ошибку дальних точек, разброс повторных попаданий
в каждую сторону и изменение ошибки возврата от первого до последнего цикла.
Постоянное недоперемещение при малом разбросе может указывать на коэффициент
STEP/мм; растущий разброс/дрейф — на потерю шагов, люфт или проскальзывание.
По одному признаку причину окончательно установить нельзя.

`estimated_steps_per_mm` — оценка коэффициента по измеренному ходу. Применять
её можно только после исключения пропусков шагов и проскальзывания; иначе
она маскирует проблему. Расчётная дискретность 0,025 мм не равна гарантированной
механической точности.

Сначала проверьте медленный режим, затем ту же длину при 600, 400, 300 мс.
Дополнительно сравните ходы 25, 50 и 125 мм. Этот тест проверяет попадание
в конечные точки после остановки; точность траектории между ними и непрерывную
работу на 160 BPM он не измеряет.

Проверка расчётов и интерфейса без подключения мотора:
`python tools/check_accuracy_test.py`. Сборка: `pio run -e tmc2209_accuracy_test`.

В V2 исправлен повторный запуск в прежнем направлении, если прерывание
таймера завершало движение прямо перед проверкой следующего запуска.
Каждый переезд теперь требует отдельного разрешения; для точности оно
выдаётся после записи измерения. Старую V1 окно не принимает.
Проверка этого случая и чередования направлений реального кода прошивки
без мотора: `python tools/check_fret_sequence.py` (нужен g++).
