# Тест скорости TMC2209

Подключение Uno: STEP → D2, DIR → D3, EN → D4.
Тест калибровки использует те же выводы. Переставлять провода не нужно.
Питание логики 5 В,
питание мотора от отдельного БП, общий GND. Сначала настройте ограничение тока.
Испытывайте свободный вал без каретки и других ограничений хода.

## Загрузка прошивки

В PowerShell из корня проекта:

```powershell
& "$env:USERPROFILE\.platformio\penv\Scripts\platformio.exe" run -e tmc2209_speed_test -t upload
```

Закройте монитор последовательного порта, затем откройте окно управления:

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\start_speed_control.ps1
```

Выберите COM-порт Arduino, нажмите «Подключить», подождите 3 секунды.
Выберите микрошаг, настроенный на TMC2209. Это поле только меняет пересчёт
показаний, сам драйвер оно не настраивает. В окне и журнале выводятся расчётные
об/мин и цель следующей ступени. Изменять прошивку для этого обновления не нужно.
«ПУСК» или Enter запускает разгон; «СТОП», пробел или Esc прекращает импульсы
и отключает драйвер. Вал может двигаться по инерции. Клавиши действуют,
когда окно программы активно. Программа автоматически мотор не запускает.

Начальная частота 100 импульсов/с, ускорение 500 импульсов/с².
Первая цель 200 импульсов/с; далее прибавляется максимум из 200 импульсов/с
и 10% предыдущей цели. На каждой ступени частота удерживается 4 секунды.
Заданный предел генератора Uno на D2 — 100 000 импульсов/с (3750 об/мин при 1600
импульсах на оборот), после него автоматическая остановка. Это технический
предел этого теста, а не измеренный максимум мотора. Срыв вращения нужно
определять наблюдением и нажимать «СТОП». Частота в журнале учитывает
округление периода Timer1; точность физического сигнала проверяется
осциллографом или логическим анализатором. Timer1 вызывает прерывание
для каждого импульса на D2, высокий уровень удерживается примерно 2 мкс.
На большой частоте прерывания Serial и Timer0 могут вносить джиттер.
100 кГц — выбранный предел программы, а не измеренная гарантия сигнала.
200 кГц на D2 в этой реализации не поддерживаются. Режим потребует
исключительного использования Timer1; Servo и другие библиотеки,
использующие Timer1, несовместимы.
Потеря heartbeat на 2 секунды также останавливает импульсы и отключает драйвер.
При закрытии окна отправляется команда остановки.

Значения pulse_rate — заданная частота STEP, а не измеренная скорость вала.
Без энкодера тест не обнаруживает пропуски шагов или заклинивание.
Если вал остановился, дёргается или мотор визжит, нажмите «СТОП» и запишите
последнюю устойчивую частоту. Повторный «ПУСК» начинает разгон сначала.
Последняя частота перед остановкой остаётся в журнале окна.

Для мотора с шагом 1,8°: об/мин = pulse_rate × 60 / (200 × микрошаг).
Микрошаг определяют по настройкам именно TMC2209; интерполяция до 256
не меняет число входных импульсов на оборот. Не используйте настройку
«полный шаг» A4988 как предположение для TMC2209.

Окно использует tkinter обычного Python и pyserial из установленного PlatformIO.
Если используется другой ПК: установите Python с tkinter и `pip install pyserial`,
затем запустите `python tools/tmc2209_speed_control.py`.
