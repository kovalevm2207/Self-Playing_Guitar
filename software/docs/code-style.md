# Стиль кода

За основу взяты `.clang-format`, LLVM 18 и организация сборки проекта `triangles`.
Конфигурация `.clang-format` скопирована целиком, без замены на неявные defaults.

- C++17; четыре пробела; ограничение строки 85 символов; указатели и ссылки у типа.
- Одно действие и одно объявление на строку. Фигурные скобки у ветвлений и циклов.
- Пустая строка разделяет функции и логические этапы: проверка входа, подготовка
  данных, изменение состояния, уведомление интерфейса.
- Имена передают смысл и единицы измерения: `durationMs`, `m_responseTimeout`,
  `m_expectedResponse`. Однобуквенные имена оставляем коротким индексам циклов.
- Числовые параметры соединения именуем константами. Комментарий объясняет
  причину решения, а не повторяет выражение.
- QML форматируется штатным `qmlformat` из закреплённого Qt: свойства и обработчики
  разворачиваются на отдельные строки.

Из Nix-окружения в каталоге `software/`:

```bash
cmake --build build/debug --target format
cmake --build build/debug --target format-check
```

Это правила оформления текущего прототипа. Границы ответственности `Backend`,
модель песни, состояние передачи и компоненты интерфейса предстоит спроектировать
отдельно; форматирование само по себе эту задачу не решает.
